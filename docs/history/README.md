# Historical documents

The documents in this directory are development plans from Milestone 4. They
describe the plans for the wallet and the demonstration before version 1.0.
Version 1.0 changed the wire format, the keys, and the deposit and withdrawal
flows. Thus, these plans do not agree with the current code.

| Document                          | Content                                        |
| --------------------------------- | ---------------------------------------------- |
| `wallet-integration.md`           | The plan for the wallet back end and front end |
| `wallet-integration-checklist.md` | The task list for that plan                    |
| `demo-plan.md`                    | The plan for the two-wallet demonstration      |

For the current system, read these documents:

- `docs/spec/protocol.md`: the protocol specification
- `docs/whitepaper.md`: the technical whitepaper
- `docs/implementation.md`: the implementation and operator guide
- `docs/user-guide.md`: the wallet user guide
